# Wordsmithing Skill

Improve existing copy at the paragraph level.

The core promise:

> Same meaning. Stronger words.

## Operating Standard

Make the copy feel:

- clear,
- fast,
- specific,
- emotionally awake,
- direct-response,
- easy to read,
- easy to say out loud.

Use Alex Hormozi-style direct-response clarity:

- plain spoken language,
- one clear idea at a time,
- fast emotional entry,
- real-world stakes,
- simple words with strong rhythm,
- 8th-to-10th-grade clarity without sounding dumbed down.

Use Hormozi-style pressure where it fits:

- sharpen the dream outcome,
- expose the cost of delay,
- make the payoff feel bigger,
- make the effort feel smaller,
- turn vague value into concrete value,
- raise urgency through consequence, speed, contrast, or specificity.

Use positive framing when handling doubts:

- answer the concern without leading with the unwanted idea,
- phrase guarantees around confidence and safety,
- phrase objections around reassurance and clarity,
- remove wording that plants the exact fear the copy is trying to overcome.

Example:

- Strong: "100% money-back guarantee."
- Weak: "If this is not worth the money, ask for it back."

Example:

- Strong: "What happens during the seminar?"
- Weak: "Is this a sales pitch dressed up as a seminar?"

## Paragraph Method

For each paragraph:

1. Find the one thing the paragraph is trying to say.
2. Cut throat-clearing, filler, and slow setup.
3. Replace vague language with concrete outcomes.
4. Add emotional consequence where the idea is too flat.
5. Use active verbs and plain nouns.
6. Break tangled sentences into clean, spoken lines.
7. Reframe negative-leading language into confident, forward-moving language.
8. Keep the original meaning intact.

## Read-Aloud Pass

A strong line that tangles the mouth is not finished.

Check for:

- short sentences,
- one idea per sentence,
- natural breath points,
- rhythm that moves,
- words a real person would say,
- no stacked clauses that bury the point.

## Output Format

When helping decide:

```md
Recommended rewrite:
...

Why:
...
```

When the user asks to apply the change, make the edit directly.

Keep explanations short. The rewrite is the main event.
